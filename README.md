# ⚔️ Monsterdestroyer

<p align="center">
  <strong>3Dモデルの自作からUnityでの実装まで、全工程に挑戦した3D戦闘アクションゲーム</strong>
</p>

---

## 📝 概要

大学での学びや個人開発のステップとして、ゲームが形になるまでの「一連の流れ」を深く理解するために制作した3Dアクションゲームです。
アセットに頼るだけでなく、キャラクターの見た目からモーション、ゲームシステムまで、手探りながらすべて自分の手で作り上げることにこだわりました。

---

## ✨ 本作のこだわり・挑戦したこと

### 1. オリジナル3Dモデルのフルスクラッチ制作
*   **メッシュ制作（モデリング）:** キャラクターの立体的な形状をゼロから制作。
*   **リグ入れ（リギング）:** キャラクターが動くための骨組み（ボーン）とウェイトを設定。
*   **アニメーション:** 攻撃や移動など、戦闘に必要なモーションを一つひとつ自作。

### 2. Unityでの戦闘システム実装
*   自作したモデルとアニメーションをUnityにインポートし、心地よい操作感を目指して攻撃判定や戦闘ロジックをプログラミングしました。

---

## 🚀 開発を通じて学んだこと

モデル制作からアニメーション、そしてゲーム内での動かし方までを地続きで経験したことで、「3Dゲームがどのような仕組みで動いているのか」を体感的に学ぶことができました。
この経験で得た「手触りの良いゲームを作るための基礎知識」を、次回のUnreal Engineでのプロジェクトにも活かしていきたいと考えています。
